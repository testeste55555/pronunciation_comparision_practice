# 音声学データの状態

## 全体

このMVPの目的は、教師用操作画面と文字なしの学習者視聴画面、SVG口腔図、順次比較の操作性を検証することです。

現時点の調音数値は、音声学的な確定値ではありません。

| 項目 | 状態 |
|---|---|
| 日本語「し・ふ・ら」の教師向け説明 | 暫定 |
| 日本語口腔アニメーション | UI確認用暫定モデル |
| 北部ベトナム語比較候補 | UI確認用暫定モデル |
| Cebu City系セブアノ語比較候補 | UI確認用暫定モデル |
| 母語話者確認 | 未実施 |
| 音声学専門家確認 | 未実施 |
| 模範音声 | 未登録 |
| 自動採点 | 対象外 |

## 使用制限

- 国籍や言語名だけから学習者の発音を決めつけない。
- 比較候補は、教師が実際の発音を聞いた後に選択する。
- 二次元口腔図を唯一の正しい口腔形状として提示しない。
- 現MVPを発音の合否判定に使用しない。

## 次の監修作業

1. 各対象音の日本語モデルを音声学資料と実測例で確認する。
2. 北部ベトナム語の対象音に近い実現を資料から特定する。
3. Cebu City系セブアノ語の対象音に近い実現を資料から特定する。
4. 複数の母語話者に確認し、個人差と地域差を記録する。
5. 口腔図の動きを修正し、資料・監修者・更新日を各データへ付与する。
