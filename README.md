# 発音比較・口腔図アプリ

技能実習生・育成就労生等への日本語発音指導を想定した、教師提示中心の静的Webアプリです。

> **現在はUI・構造確認用仮モデルです。音声学的監修前のため授業には使用できません。**

## 公開URL

`https://testeste55555.github.io/pronunciation_comparision_practice/`

## 現在の試作範囲

- 日本語：東京方言を基礎とする共通語モデル
- 比較候補：北部ベトナム語・ハノイ系
- 比較候補：セブアノ語（Bisaya／Binisaya・Cebu City系）
- 対象音：「し」「ふ」「ら」
- 教師用画面と学習者用画面を分離
- 学習者画面は文字・IPA・専門用語・言語名・操作部品を非表示
- `BroadcastChannel`と`localStorage`による同一ブラウザ内同期

## v0.2の構造改修

- 舌を単純な一図形から、舌根・舌後部・中央部・前部・舌端・舌先の6制御点へ変更
- 母語候補から日本語への移行を、図形の消去・差し替えではなく連続補間へ変更
- 再生倍率を、舌・唇・息・声帯・舌先運動・模倣待機へ共通適用
- 舌先のはじき／震えを、舌全体の移動ではなく舌先・舌端の局所変形へ変更
- 教師画面に「授業使用不可」を明示
- CC0の音声学教育用矢状断図を、固定コミット・ハッシュ照合で教師用基準資料として取得

これは真正性の完成ではなく、**真正な資料と監修値へ差し替えられる構造への移行**です。

## 使い方

1. 教師用画面を開きます。
2. 「学習者画面を開く」を押します。
3. 学習者画面をプロジェクターまたは外部ディスプレイへ移動します。
4. 教師画面で比較候補、対象音、提示内容、倍率を選択します。
5. 緊急時は「即時に無地」を使用します。

## ローカル起動

```bash
bash ./scripts/fetch_reference_assets.sh
cd site
python -m http.server 8000
```

## テスト

```bash
node --test tests/model.test.mjs
```

GitHub Pagesのワークフローでも、JavaScript構文確認、モデル検証、基準資料のハッシュ照合を実行します。

## 音声について

現試作には模範音声を収録していません。ブラウザTTSも正確な発音モデルとして採用していません。

権利・話者同意・公開範囲を確認した音声だけを`site/assets/audio/public/`へ配置します。

## `.gitignore`の設計

公開リポジトリを前提に、`.env`、認証情報、学習者録音、個人情報、未許諾音声、private／staging／raw領域、生成物、ログ、バックアップ等をGit管理対象外としています。GitHub Pagesは`site/`だけを公開します。
